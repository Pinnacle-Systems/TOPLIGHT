## ⚡ Quick Start for Tests

```bash
# 1. Run full E2E test suite (Backend + Mobile)
pnpm test:e2e

# 2. Run Express.js backend API tests
pnpm test:e2e:backend

# 3. Run React Native Appium mobile tests
pnpm test:e2e:mobile
```
